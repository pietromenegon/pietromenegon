### What CentralPi does

- Online store and in-store sales (POS) in one system
- Inventory that updates itself with every sale
- Finances: what came in, what went out and what was left at the end of the month
- Commission on every sale, and each employee sees only what is theirs
- Modules for each kind of business: salons, spas, pet shops, auto care, fashion, repair shops and more

Like π (3.14159…), which never ends, the system keeps evolving with each business, one module at a time.
